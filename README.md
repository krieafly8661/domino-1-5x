# ドミノは1.5倍

5mmのドミノから始めて、30枚でどこまで大きなドミノを倒せるかを競うブラウザゲーム。
**遊ぶ：** https://krieafly8661.github.io/domino-1-5x/


## もとになった事実

ドミノは、自分の約1.5倍の大きさのドミノまで倒せます。1983年に物理学者のローン・ホワイトヘッド（Lorne Whitehead）が実験で示しました。毎回ちょうど1.5倍にすると、5mmのドミノは30枚目で約639mになり、東京スカイツリー（634m）とほぼ同じ高さです。

## 遊び方

- ボタンを押しているあいだ、次のドミノの倍率が ×1.00〜×2.00 を行き来します。はなすと、その大きさのドミノが置かれます。
- 1枚ごとに「倒せる限界」（×1.40〜×1.62）が決まっています。**限界をこえると倒れず、そこで終わり。**
- 限界のぎりぎりではなすほど大きくなります。枚数が進むほど倍率の動きは速くなります。
- 倒した最後のドミノの高さが記録です。消しゴム・大人・奈良の大仏・東京タワーなどと実物の大きさでくらべられます。

操作：スペースキーでも長押しできます。

## 動かし方

`index.html` を開くだけで遊べます。外部ライブラリは使っていません。

## このゲームを作った理由

2026年10月下旬のXでは『まじブンブンブンデカすぎて斧』『1万ボーリング』『100億ダーツ』など、規模がどんどんふくらむゲームが目立ちました。このゲームはその気持ちよさを、作り話ではなく「1.5倍」という本物の物理の数字で出しています。どこで止まったかと「〇〇超え」が、そのまま投稿になります。
